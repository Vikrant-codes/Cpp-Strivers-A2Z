🟣 Binomial Theorem & Expansion
-------------------------------------------------------------------------------------------

>> What is a binomial?
A binomial is simply an algebraic expression containing two terms.
Examples: a + b, x + 2, 2x - 3, etc.

The binomial theorem tells us how to expand a binomial raised to a power without multiplying everything manually.

For example: (a + b)² = (a + b) (a + b) = a² + 2ab + b²
Similarly, (a + b)³ = a³ + 3a²b + 3ab² + b³

Notice the coefficients:
- For power 2: 1, 2, 1
- For power 3: 1, 3, 3, 1
Where do these numbers come from? That's the interesting part.

>> Understanding the coefficients

Let's take: (a + b)³ = (a + b) (a + b) (a + b)
When expanding, we must select either a or b from each of the three brackets.

To obtain `a³`, we must select a from all three brackets.
There is only one way to do that.

To obtain `a²b`, we need:
- a from the first two brackets and b from the third.
- a from the first and third, b from the second.
- a from the second and third, b from the first.
There are three ways.
Therefore, the coefficient of `a²b` is 3.

Likewise, to obtain `ab²`, there are three ways to select two bs and one a.

Finally, there is only one way to obtain `b³`.

Hence: (a + b)³ = a³ + 3a²b + 3ab² + b³

The important observation: The coefficients represent the number of ways to select the terms from the brackets.

>> Expansion formula
---------------------------------------------
|        n         n    n      (n-k)    k   |
| (a + b)    =     Σ     C   a         b    |
|                 k=0     k                 |
---------------------------------------------

>> Pascal's Triangle
There's a beautiful pattern in these coefficients.

          1
        1  1
      1  2  1
    1  3   3  1
  1  4  6   4  1
1  5  10  10  5  1

Each number is the sum of the two numbers directly above it.

Each row gives the coefficients for the corresponding power:

Power  | Coefficients
0	   | 1
1	   | 1, 1
2	   | 1, 2, 1
3	   | 1, 3, 3, 1
4	   | 1, 4, 6, 4, 1
5	   | 1, 5, 10, 10, 5, 1

For example: (a+b)^4
Using row 4: a^4 + 4 a^3 b + 6 a^2 b^2 + 4 a b^3 + b^4

>> The connection with nCr (Combinations)

Now comes the most important connection.

Remember how we counted the ways to obtain a²b in (a+b)³ ?
We were essentially choosing which one of the three brackets contributes b.
That's exactly a combination!

We can represent the coefficients using: nCr = n! / {r! * (n-r)!}

The coefficient of a²b is: 3C1 = 3
Why? Because we're choosing 1 position out of 3 positions for b.

Similarly, the coefficient of ab² is: 3C2 = 3
We're choosing 2 positions out of 3 for b.

This gives us the general binomial expansion:
---------------------------------------------
|        n         n    n      (n-k)    k   |
| (a + b)    =     Σ     C   a         b    |
|                 k=0     k                 |
---------------------------------------------

>> One important thing: calculating consecutive coefficients

Suppose we want coefficients for (a+b)^5.

Instead of calculating every combination using factorials separately, we can calculate consecutive coefficients using:
--------------------------------------
| C(n,r+1) = C(n,r) × (n-r) / (r+1)  |
--------------------------------------

Start with: 
C(5,0) = 1

Then:

C(5,1) = 1 × 5 / 1 = 5

C(5,2) = 5 × 4 / 2 = 10

C(5,3) = 10 × 3 / 3 = 10

C(5,4) = 10 × 2 / 4 = 5

C(5,5) = 5 × 1 / 5 = 1

Notice that every division gives an integer.

This is the special relationship between consecutive binomial coefficients: 
the multiplication and division together produce the next exact combination value.

The resulting coefficients are:
1, 5, 10, 10, 5, 1

🟡 Catalan numbers
-------------------------------------------------------------------------------------------
The Catalan numbers are a sequence of natural numbers that occur in various counting problems, 
often involving recursively defined objects. 
They solve many counting problems in mathematics and computer science.
They are named after Eugène Catalan, though they were previously discovered in the 1730s by Minggatu.

The n-th Catalan number (Cₙ) can be expressed directly in terms of the central binomial coefficients by

          1                                       1             2n!                  2n!
Cₙ  =  _______   *   Combination(2n , n)   =   _______  *   __________    =     _____________       , for n >= 0
       (n + 1)                                 (n + 1)       n!  *  n!          (n + 1)! * n!

The first Catalan numbers for n = 0, 1, 2, 3, ... are
1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796, 58786, ... 

Asymptotically, the Catalan numbers grow as
                  4ⁿ
Cₙ  ~       ______________
            n^(3/2) * √ π

>> Common Applications
Catalan numbers show up when counting

- Parentheses: Valid ways to match `n` pairs of parentheses (e.g., for n=3, [ ((())), ()()(), (()()), (())(), ()(()) ] ).
- Binary Trees: Unique binary search trees or full binary trees with n + 1 leaves.
- Polygons: Ways to cut a convex (n+2)-sided polygon into triangles using non-intersecting diagonals.
- Grid Paths: Routes on an n * n grid that do not cross the diagonal.

🟡 Golden Ratio (φ ≈ 1.618)
-------------------------------------------------------------------------------------------
🔹 The golden ratio is: 𝜑 = (1 + √5) / 2 
🔹 Represented by Phi (φ or 𝜑)
It appears when something is divided in the “most balanced” way.

🧠 Why it’s special
- It’s irrational → never repeats → no patterns → (non-terminating non-repeating)
- It shows up in nature, art, and math
- It has a self-relation: 𝜑² = 𝜑 + 1

⚡ In programming
1. Fibonacci connection
Fibonacci numbers grow like: 𝐹(𝑛) ≈ 𝜑^𝑛
👉 That’s why Fibonacci grows fast and appears in complexity analysis.

2. Hashing intuition
- Because φ is pattern-free, it helps in:
- spreading values uniformly
- avoiding clustering
👉 This idea leads directly to constants like 0x9e3779b9.

🔥 Core idea
👉 Golden ratio = perfect distribution without patterns

🟢 1e9+7 (1000000007)
-------------------------------------------------------------------------------------------
🔹 What it is: A large prime number: 1e9 + 7 = 10^9 + 7 = 1000000007

🧠 Why it’s special
✅ 1. It’s PRIME
Because it's a large prime number it is used extensively in modular arithmetics.

✅ 2. Fits in 32-bit range
- Less than 2^31
- Safe for int operations (with care)

✅ 3. Prevents overflow
Instead of: long long x = a * b; // may overflow
We do: (a * b) % mod

⚡ In programming
1. Competitive Programming
- Used everywhere:
- DP problems
- Combinatorics (nCr)
- Graph counting

2. Modular arithmetic rules
- (a + b) % mod
- (a * b) % mod
- a^b % mod (fast exponentiation)

🔥 Core idea
👉 1e9+7 = safe + prime + overflow protection

🔵 0x9e3779b9 = 2654435769 (Golden Ratio Constant)
-------------------------------------------------------------------------------------------
🔹 What it is: 
Hex value: 0x9e3779b9
Decimal: 2654435769

🧠 Where it comes from
It is derived from the golden ratio: ⌊ 2^32 / 𝜑 ⌋
i.e., the floor value of 2^32 divided by golden ratio.

👉 Basically: golden ratio scaled to 32-bit integer space

⚡ Why it’s special
✅ 1. Excellent bit mixing
When used in hashing:
- spreads bits evenly
- avoids collisions

✅ 2. No patterns
Because it comes from φ:
- behaves “random-like”
- breaks regular structures

⚡ In programming
1. Hash combining
    hash ^= x + 0x9e3779b9 + (hash << 6) + (hash >> 2);
👉 Used in: unordered_map custom hash

2. Prevent hacking (CP): Avoids worst-case collisions in hash tables.

3. Randomization / scrambling: Used in pseudo-random generators and bit manipulation tricks


• φ (1.618) → avoids patterns in math
• 0x9e3779b9 = 2654435769 = 2^32 / φ → avoids patterns in bits
• 1e9+7 → avoids overflow in computations
